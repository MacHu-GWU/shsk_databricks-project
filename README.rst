Install
------------------------------------------------------------------------------

``shsk_databricks`` is released on PyPI, so all you need is to:

.. code-block:: console

    $ pip install shsk-databricks

To upgrade to latest version:

.. code-block:: console

    $ pip install --upgrade shsk-databricks
